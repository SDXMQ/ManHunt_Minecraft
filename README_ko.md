# ManHunt 🏹

🌐 **언어 / Language**: [English](README.md) | **한국어**

> **Kotlin**으로 개발된 강력하고 안정적인 **Minecraft Paper 플러그인** 기반의 맨헌트(Manhunt) 미니게임입니다.  
> 러너(Runner)는 엔더 드래곤을 처치해야 하며, 헌터(Hunter)는 러너를 추적하여 사냥해야 합니다.

---

## ✨ 주요 기능

- 🧭 **직접 제작하는 실시간 러너 추적 나침반**
  - 게임 시작 시 나침반이 자동 지급되지 않으며, 플레이어가 직접 제작해야 합니다.
  - 일반 나침반을 들고 **우클릭**하면 헌터 1명당 1개만 소지 가능한 `러너 추적 나침반`으로 변환됩니다.
  - 1초 주기 및 우클릭 시 같은 월드 내 **가장 가까운 생존 러너**의 위치로 타겟(`compassTarget`)이 자동 갱신됩니다.
- 💓 **스릴 넘치는 심장박동 감지 시스템**
  - 헌터가 러너 주변(기본 50블록)에 접근하면 러너에게 워든 심장박동 사운드, 베이스 음향, 액션바 경고가 출력됩니다.
- ❄️ **안정적인 사망 및 동결(Freeze) 메커니즘**
  - **헌터 사망 시**: 리스폰 직후 사망 위치에 동결(물살, 넉백, 밀치기 등 외부 요인에 의한 이동 완벽 차단, 시야 회전은 가능)되며 카운트다운 후 부활합니다.
  - **러너 사망 시**: 살아있는 다른 러너가 남아있다면 즉시 관전 모드(`SPECTATOR`)로 전환되어 게임을 지켜보며, 전원 사망 시 헌터 승리로 끝나며 서바이벌 모드로 복구됩니다.
- 🛡️ **동시성 및 엣지 케이스 방어 설계**
  - 개별 루프(`while` + `wait`) 대신 **단일 글로벌 틱 루프**로 전역 상태를 평가합니다.
  - 플레이어 객체가 아닌 고유 식별자(`UUID`) 기반으로 상태를 관리하여, **사망 대기 중 서버 튕김, 재접속 시에도 동결 시간 및 상태가 안전하게 복원**됩니다.
- ⚙️ **인게임 실시간 설정 GUI (`/manhunt option`)**
  - 체스트 인벤토리 UI를 통해 심장박동 감지 반경, 헌터 출발 대기 시간, 부활 대기 시간, 러너 패배 판정 모드(전원 사망 vs 1명 사망)를 인게임에서 실시간 변경할 수 있습니다.
- 🌐 **한/영 이중 명령어 트리 완벽 지원**
  - `/맨헌트` 및 `/manhunt` 명령어와 각 하위 명령어를 단일 핸들러로 공유하여 동일하게 사용할 수 있습니다.

## 📜 명령어 및 권한

### 관리자 권한
* **노드**: `manhunt.admin`
* **기본값**: `OP`

### 명령어 목록
`/맨헌트`와 `/manhunt`는 완전히 동일하게 작동하며, 영문과 한글 서브커맨드를 교차하여 사용할 수도 있습니다.

| 한국어 명령어 | 영문 명령어 | 설명 |
|---|---|---|
| `/맨헌트 시작` | `/manhunt start` | 맨헌트 게임을 시작합니다. (러너 외 인원 자동 헌터 배정) |
| `/맨헌트 종료` | `/manhunt stop` | 진행 중인 게임을 강제 종료하고 상태를 초기화합니다. |
| `/맨헌트 러너 <플레이어>` | `/manhunt runner <플레이어>` | 특정 플레이어를 러너로 등록하거나 해제합니다. |
| `/맨헌트 설정` | `/manhunt option` | 게임 설정 GUI 창을 엽니다. |

> 💡 **스마트 탭 자동완성**: `/manhunt ` 입력 시 영문 서브커맨드가 우선 추천되며, `/맨헌트 ` 입력 시 한글 서브커맨드가 우선 추천됩니다.

## 🎮 게임 규칙 & 승패 판정

1. **게임 준비**:
   - 관리자가 `/manhunt runner <플레이어>` 명령어로 러너를 지정합니다. (여러 명 지정 가능)
   - `/manhunt start`로 게임을 시작하면, 러너를 제외한 모든 플레이어가 **헌터**로 자동 지정됩니다.
2. **출발 대기**:
   - 헌터들은 설정된 시간(기본 60초) 동안 이동이 제한(동결)되며, 카운트다운 완료 후 출발합니다.
3. **승패 판정**:
   - **러너 팀 승리**: 엔더 드래곤을 처치하면 러너 팀이 승리합니다.
   - **헌터 팀 승리**:
     - `모든 러너 사망 모드 (기본값)`: 모든 러너가 사망했을 때 헌터 팀이 승리합니다. (도중 사망한 러너는 관전 모드로 대기)
     - `러너 1명 사망 모드`: 러너 중 1명이라도 사망하면 즉시 헌터 팀이 승리합니다.

## 📦 빌드 및 설치 방법

### 요구사항
- **Java**: JDK 25 이상
- **서버 소프트웨어**: Paper 26.2 이상 (또는 호환되는 상위 버전)

### 빌드 명령어
```bash
# Gradle Wrapper를 통한 ShadowJar 빌드
./gradlew shadowJar
```

### 서버 적용
빌드가 완료되면 `build/libs/` 디렉토리에 파일이 생성됩니다.
- ⚠️ 반드시 **`-all.jar`** 로 끝나는 파일(예: `ManHunt-1.0-SNAPSHOT-all.jar`)을 복사하여 서버의 `plugins/` 폴더에 넣어야 합니다. (Kotlin 런타임 라이브러리가 포함된 Fat JAR입니다)
- 서버를 시작하거나 재부팅하면 플러그인이 로드됩니다.
